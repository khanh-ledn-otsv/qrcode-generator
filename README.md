# QR Code Generator

A client-side Leptos application styled with Tailwind CSS.

## Run locally

```sh
rustup target add wasm32-unknown-unknown
trunk serve --open
```

Trunk builds the Rust application to WebAssembly and compiles Tailwind CSS automatically.
